## 六 本口径不覆盖什么（诚实清单）

1. **快照字段实现方案未被行为断言独占验证**：D1 主推"新增两字段"，但 A′ 共享纯函数（design §3）在行为面等价；本文断言只钉"文案＝施加时实际值"，**不区分 B 方案 vs A′**。若主理人要验"确有两字段且 clear 复位"，须另加白盒静态门（超出行为口径）。
2. **clear 漂移路径被 D1 复位规则挡住**：已在 §1.1 标注 D1 与 design §8.3 冲突，本文不验"clear 后 id 未清仍报施加档位"；该路径要么按主理人裁定补断言，要么随 id 清空一并显示"无"（现行流程 `:1061-1063` 即如此），不构成漏测。
3. **0 增量/0 削减的自然可达性未证实**：两态经 apply 不可达，F0/A0 为合成前提守卫；若后续引入可把快照压到 0 的机制，须重判其覆盖等级。
4. **机制/数值零覆盖＋人眼可读性**：applier 施加值、clear 还原、压力抬倍率属既有断言范围，本批不改不重验；只机检"首词保留＋数字对＋0 不写 0%"，语感由主理人 Playtest。
5. **层签刷新时机未被全量覆盖**：F2/A2 各造一次层签漂移；生产路径里 tick/主题重建/换层多处会刷层签，本文只钉"漂移后文案稳定"这一性质，不逐刷新点枚举。
