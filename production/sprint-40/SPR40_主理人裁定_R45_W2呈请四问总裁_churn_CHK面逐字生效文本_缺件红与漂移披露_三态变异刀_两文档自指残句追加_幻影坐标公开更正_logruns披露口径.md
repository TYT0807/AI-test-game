## §A 事项 1 总裁：churn CHK 面的逐字生效文本（W2 主体）

### A-1 定性维持 R20 §E-2，两型假绿均坐实

### A-2 Q1-a 裁：**缺件红＋漂移一律红**（取「如实红」，不取「漂移只披露」）

R20 §E-2 原句「存在且漂→RED 由内容判定决定」留的口子，本窗用 §0-4 的实测内容把它缝死，理由两条：

1. 「由内容判定」在 shell 里没有可判别的东西——机检件输出全是自由文本计数行，任何自动分级都等于再造一台需要自己验收的判据机；人工分级则回到「靠有人记得看」，正是 selfaudit :218 批判的形状。
2. 更硬的证据：**当前盘上合法的「改前 vs 改后」本来就必然漂**。§0-2 的两处漂移（`equip_calls 14→29`、`应解析 285→287`）都是产品面正当演变带动机检件读数正当变化。⇒ 若「漂即红」，churn 的 CHK 面将**永远红**，红就失去信号量；若「漂只披露」，它今天就在替假绿开门。两难说明 **GREEN/RED 的二值本来就不是这个面的正确语义**——它的正确语义是 §0 第 6 行披露的现状：**CHK 面不在门禁链内，它是 HP-0 对照轮的披露性证据面**。

因此裁定如下三层语义（生效文本见 A-3）：
- **缺件 ⇒ `RED=1`**（硬红，零输入不许绿，与 :17 同款）；
- **存在且漂 ⇒ 打行、披露明细、不置红**，行尾固定 `RED 判定=披露不置红（机检件读数随产品面合法演变）`，让下游 grep 一眼能分「漂而未红」是设计而非漏；
- **存在且同 ⇒ GREEN**。

这条同时是对 R20 §E-2 那句「由内容判定决定」的**正式改写裁定**（本件即「主理人下轮裁」的那一轮），不是违背它——它本来就写明具体逐字文本由本流程定形。

⚠ 随之而来的账（如实报，⛔ 顺手抹）：一旦落地，**11:0x 代对照（BASE=spr40_base／AFTER=spr40_after）重放必打 `red=2`（quota+taut 漂，披露）或按新文本 `red=0`＋两行披露漂＋0 缺件；12:0x 代对照（`*_r17`）必打 `red=5`（全缺件）**。这不是回归坏，是把一直存在的盲区申报出来。12:0x 代要补齐 CHK 五件再谈该代 churn——补建动作挂 §E 待裁清单 E-4，本件不授权任何人替 `*_r17` 目录**造** chk 件内容（那必须是判据件真跑一遍的产物）。

### A-3 Q1-b 裁：逐字生效文本（整段替换 `spr40_churn.sh` 现读 :44-52；:44 的 echo 标题行原样保留）

编程侧呈请版有两处必须纠：①`:62` 那行右括号漏了（呈请自己已标注）；②按 A-2，漂移分支不能 `RED=1`。以下为**照抄即用**的最终文本（bash 语法本窗已做只读校验逻辑推演；施工窗落地后 `bash -n` 是硬前置）：

```bash
echo "--- 机检件（chk_*／clause）改前后 cmp ---"
for c in spr38_g_chk_fp spr38_g_chk_quota spr38_g_chk_taut spr38_g_chk_verbatim spr38_g_clause; do
	_b="$BASE/$c.txt"; _a="$AFTER/$c.txt"
	if [ ! -f "$_b" ] || [ ! -f "$_a" ]; then
		echo "CHK $c RED 缺件 base=$([ -f "$_b" ] && echo 有 || echo 无) after=$([ -f "$_a" ] && echo 有 || echo 无)"
		RED=1
	elif cmp -s "$_b" "$_a"; then
		echo "CHK $c GREEN 逐字节相同"
	else
		echo "CHK $c 漂移 ⇒（RED 判定=披露不置红，机检件读数随产品面合法演变）"
		diff "$_b" "$_a" | grep -a "^[<>]" | head -8
	fi
done
```

施工注意（🔴 硬约束）：
- 循环体内临时变量**必须用 `_b`/`_a`**（或与 :15-32 一致的其它新名），⛔ 裸用 `b`/`a`——:15-32 那个循环已经占用它们，虽然顺序执行不会立刻出错，但任何后续人在 CHK 段之后引用 `b` 都会拿到上一段的残留值（本项目最恨会腐烂的隐式状态）。

- `echo` 末行 `CHURN-DONE red=$RED …`（现读 :54）**一字不动**——它就是判定串的行尾锚。
