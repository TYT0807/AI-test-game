## §F-4 给 R95 的新闸建议

1. **注入生效性闸**（针对 §D-④）：常驻引文门禁刀须自证「注入的那一类真的进了语料」——`注入语料=N 类` 且 `语料目录=k/k 全在盘` 才允许判 GREEN；缺目录只 WARN 的形状＝静默降级面，HP-8 拦不住（它拦零输入，不拦「少一路输入」）。同时把文档面示例调用行纳入可执行性自校准：示例行本身跑不出 RC=0 ⇒ 文档面判红（R93 §F-4③ 的加强形：不止「引用他车尺子」，**自己 README 里的例子**也在靶内）。

4. **证件号⇄自报号车外核**（针对 §D-①）：独立结论刀须对每份被引证件做一次「文件内部自报的趟号==文件名号」核（刀内看不见自己的重定向落点，这条只能车外跑）；本车 E0c 只覆盖了洞与膨胀形。
