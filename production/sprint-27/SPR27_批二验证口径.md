### 1.3 单条断言规范 + 四条实现细节

**四项必填**（同批一）：验什么（点名字段 + 直调/真实路径）· 怎么构造（`last_run` 字面量、基线拉平、daily 开关）· 期望值怎么取（**字面量**，禁在探针里读 `Data` 反推）· 失败信息含实测/期望/构造。
样板：
```gdscript
_og_assert(_oath_grant_amount(3) == 8, "A04 s=3 → 8",
    "%d" % _oath_grant_amount(3), "8")
```
```gdscript
func _og_assert(ok: bool, nn_name: String, measured, expect) -> void:
	_og_checked += 1
	Dev.check(ok, "oath_grant", "%s | measured=%s expect=%s" % [nn_name, str(measured), str(expect)])
	print("[SMOKE-OATH-GRANT] #%02d %s measured=%s expect=%s" % [_og_checked, nn_name, str(measured), str(expect)])
```

**① A 组是纯函数，基线无关**：`_oath_grant_amount(s)` 只吃一个 int（实施单 §1.1 设计意图），**不得读 `Game` / `player`**（F02 就是这条守卫）。故 A 组**不需要拉平任何基线**；需要拉平的是 B/C/G 组（`Game.diamonds`、`_oath_counters`、`run_diamonds_earned`、`_reso_pickups`、`has_resocore`）。

### 4.2 探针跑法与门控

```bash
GODOT="D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe"
# 探针（⚠️ 不带 SMOKE_META_FINGERPRINT / SMOKE_RUN_START）
SMOKE=1 SMOKE_SEED=12345 SMOKE_OATH_GRANT=1 "$GODOT" --headless --path . --quit-after 900 2>&1 | tee og.log

grep -c "wire_fail" og.log                   # 期望 0（call() 无静态检查，运行期自证接上了）

for s in 12345 777 42; do
  SMOKE=1 SMOKE_SEED=$s SMOKE_META_FINGERPRINT=1 "$GODOT" --headless --path . --quit-after 1800 2>&1 \
    | grep "\[SMOKE-META\] fingerprint"
done
```
**判 PASS 四条同时成立（缺一不算过）**：
1. `#NN` 行 **== 43** 且 `[ERR] oath_grant` **== 0** 且 `checked=43 declared=43` 且 **`ok=PENDING` == 0**（反向门：**"没有未判定"本身要被查一遍**，不靠没人写）；
2. **E04/E05 在探针内判绿**（三锚点限定 `start_run()` 函数体，`body` 不为 `(-1,-1)`），且 `e04e05 detail` 打出的三个行号与 `grep -nE` 实测值一致（**两处不一致 = 有人改了文件却没重跑，按 FAIL**）。⚠️ `grep` 是**交叉核对**，不是判定本体——判定本体在探针里；
3. **九刀逐刀见红，红集合与 §3.1 对齐**（不一致就必须解释结构原因，不许改期望值凑绿）；
