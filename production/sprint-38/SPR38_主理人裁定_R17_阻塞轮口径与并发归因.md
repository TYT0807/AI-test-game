## R17-1 并发红的回写件口径 → 采 **B**（A＋归因前置三条件），阻塞轮模式随 R10 转录落地自动失效

**裁定**：编程侧推荐方向成立，但只准以 **B** 的形态成立。裸 A 有一处不可接受的松弛——它把「红已归因」
这个前提整个丢了，等于给未来任何一轮发了一张免检牌：自己改坏了产品码也可以写阻塞轮行。归因三条件
不是官僚手续，是把 B 与 A 区分开的全部内容。

**归因前置三条件**（齐备才许用阻塞轮模式，缺任一 ⇒ 该轮按 §5 教训如实记 `UNEXECUTED(红未归因)`，⛔ 落流水）：
1. `drift_extra_all_after_snapshot == true`——超出 R10 十件的漂移件 mtime 全部晚于本窗起跑锚
   （R33 现值：锚 `_tools/_wb_bak_r33/AUTORUN_LEDGER.md` 18:16:05，`bullet.gd` 18:53:27，真）；
2. `tool_edits_has_scripts_path == false`——`_tools/_tool_edits.md5` 全文不含 `scripts/` 路径，本窗零产品码
   改动可自证（R33 现值：`grep -c 'scripts/'` ＝ 0，本窗复核一致）；
3. `protect_changed_n` 逐一可解释——每个 PROTECT 变化件必须挂一条在册授权（R17-5 的 AGENTS.md 即在册项），
   其余红格（C10a／selfaudit／selcmp）各自有 gist 内实测字段背书。

**成文口径（即刻生效，改的对象只有 `spr38_rNN_wb_mk.py` 模板，⛔ 门禁本身）**：
- 落笔前置闸从「`probes_all_zero is True`」改为「**行内声称与 gist 实测逐字相等**」：
  `TICKET_MATCHES_GIST=true` 是**唯一**落笔资格判据；
- 阻塞轮行首 banner 固定串 **`【BLOCKED 阻塞轮】`**，行内 ⛔ 出现 `PASS`／`全绿` 两词（机检字面串，见验收③）；
- 绿否降级为**行内报数字段**，照实报，不再是落笔资格。

**① 阻塞轮行固定字段清单**（顺序即行内出现顺序，全部现读、⛔ 引用上轮值）：
`tip` → `frozen ok/failed/total` → `FAILED集==gitM集` → `verify checks/ok/red/unexecuted` →
`red_items`（逐格名）→ `selftest_rc` → `selfaudit_rc/issues` → `selcmp a/b/only_a/only_b` →
`face5_verdict` → `probes_all_zero` → `drift_extra_files(+mtime)` → `tool_edits_has_scripts_path` →
`protect_changed_n/unchanged_n` → `falsify 本轮态数(历史重跑值)` → `flow_struct` → `banner`。

**② `probes_all_zero=false` 时是否附归因四件套**：**要**。`face5_verdict=RED` 的阻塞轮行必须同轮携带
**归因四件套**：`(a) drift_extra_all_after_snapshot` 实测值＋锚点文件与锚时间；`(b) _tool_edits.md5` 的
`scripts/` 命中计数（现读命令与输出）；`(c) RED 格逐项点名`（如 `C10a 绿件==盘上件==台账串`）；
`(d) protect_changed_n` 与变化件的在册授权引用（R33 即本件 R17-5）。四件缺一 ⇒ 回到「缺任一」分支记
`UNEXECUTED(红未归因)`。

**③ R10 转录落地后 A/B 模式是否自动失效**：**是，自动失效，无需另裁**。失效判据做成机检而非记忆：
当 `md5sum -c` 现读的 FAILED 集 ⊆ R10 稿登记的 10 件、且各 FAILED 件盘上 md5 ＝＝ R10 登记值
（即 C10a 那把刀自然转绿），mk 模板的阻塞轮分支即失去前提——此后 `probes_all_zero=false` 一律
`UNEXECUTED`，回到「必须绿才落 PASS 语义」。禁止在转录落地后继续拿 B 模式当挡箭牌；这条本身就是
防「窗口期变永久期」的闸。

**验收判据**：①R34 起的阻塞轮行首含字面串 `【BLOCKED 阻塞轮】` 且行内含上述十七段的点名串；
②变异刀反证：手工把 gist 里任一数值改掉再喂 mk ⇒ 必须拒绝落笔（`TICKET_MATCHES_GIST=false`）；
③字面串机检：`grep -a '【BLOCKED 阻塞轮】' 行 && ! grep -aE 'PASS|全绿' 同一行`；
④归因四件套缺任一件 ⇒ mk 输出 `UNEXECUTED(红未归因)` 且不写流水行（一次性夹具件，命名带
`selftest` 子串入 CHAIN_EXCLUDE 族，R16-2(c) 同款纪律）。

## R17-2 falsify 计数口径 → 主报**本轮 spec 态数**，括号附**历史重跑总数**，两者都要出现

**裁定**：流水行报数格式固定为
`falsify 本轮=<N>（历史重跑合计=<M>，labels=<L1/L2/…>）`。
理由：跨轮可比的是本轮 spec 态数（分母随当轮回写包落点数走）；历史重跑总数是**质量证据**不是计数口径，
混进主位会让下轮无法预测（R33 现值：本轮 31、历史 19＋20、合计 70——若主报 70，下轮 spec 加一态会显示成
「−39」这种荒谬读数）。旧台账的单轮值序列⛔ 追平改写，只在下一行起用新格式（append-only）。

**验收判据**：R34 流水行可直接读出 `本轮=` 与 `（历史重跑合计=` 两个字段且满足恒等式
`本轮 + Σ历史 = 合计`（R33 换算示例：`本轮=31（历史重跑合计=70，labels=R31/R32/R33-self）`——注意
31 是本轮自证、70 是三次跑的总和，`本轮` 字段取**当轮那份 spec 的态数**，`合计` 取**当轮实际执行的
全部 spec 态数之和**，mk 件按此定义实现，⛔ 自行换义）；反证＝删掉括号段 ⇒ 格式机检红。

   DECLINE 轮连跑都没跑，套 PARTIAL 会把「没跑」伪装成「跑了部分」——正是 §5「只验标志不验数值」那类
   假绿的文档版。行内照常带 R17-1 十七段字段，Godot 依赖段整段填 `UNEXECUTED`，banner 用
   `【BLOCKED 阻塞轮】`，归因四件套照常附（锁的 owner/step/mtime 即 (a) 件的一部分）。
