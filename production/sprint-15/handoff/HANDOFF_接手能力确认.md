## 二、断开后的执行链

```
用户给任务
  → team-lead 阶段诊断 + 出规格（自包含草案 / 任务单）
  → engineering-lead 实读挂接点 → 小步实施 → 自测
  → quality-lead 四门控 + 断言有效性判定
  → team-lead 读码核验（PASS / CONCERNS / final PASS）
  → 冻结重定 → 交付文档 → 单独提交（须用户授权）
```

**硬规矩不变**：成员之间禁止直连，所有产出经主理人中转汇编；任何 `.gd` 写入、git 提交、发布、删除须用户许可；改前备份、先方案后落地、小步可回滚；每批一个 commit。
