## 一、F1 · 敌人 AI 参数化

**问题**：`slug.gd` 只有 8 个 AI 函数（chase / erratic / spitter / turret / bomber / leap / summon / boss），弹速、射速、射程、弹幕数、夹角、冲刺速度全**硬编码在函数里**，28 种敌人因此手感趋同，玩家只认得出「追我的」和「射我的」。

**做法**：把行为参数抽成 `Data.AI_OVERRIDES`（按敌人 id 覆盖），AI 函数改为读字段、缺省值即原硬编码。

| 参数 | 含义 |
|-|-|
| `ai_range` | 开火 / 触发距离 |
| `ai_cd` | 射击 / 动作间隔 |
| `ai_burst` | 弹幕数 |
| `ai_spread` | 弹幕夹角 |
| `ai_bullet_speed` / `ai_bullet_dmg` | 弹速 / 伤害 |
| `ai_keep` | 保持距离（>0 表示边打边退） |
| `ai_dash` / `ai_dash_time` | 冲刺速度 / 时长 |
| `ai_n` | 召唤数 |
| `ai_sway` / `ai_sway_amp` | 飘忽频率 / 幅度 |

已差异化配置 16 种：怨灵（远程快射 300 距离）、食人花（慢速远程 80 弹速）、火骷髅（三连扇形）、眼魔（四发弹幕 340 距离）、吸血鬼（冲刺 320）、狼（冲刺 280）、牛头人（冲刺 300）、蘑菇人（召唤冷却 5 秒 / 3 只）、小鬼与妖精（飘忽频率与幅度不同）、骷髅王（4 发 0.22 夹角）、炎魔（5 发 0.26 夹角 160 弹速）、黑龙等。

**收益**：以后加怪只改这张表，不碰 AI 代码。自检 `validate._check_ai_params()` 会校验「敌人 id 存在 / 参数键合法 / 数值必须为正」。

## 三、E1 · 设置与主菜单

**做法**：单场景覆盖层（新增 `scripts/menu.gd`，CanvasLayer layer=200），**不引入多场景切换**，风险最低。

- **主菜单**：开始游戏 / 设置 / 退出游戏（启动即显示，游戏在背后暂停）
- **暂停菜单**：继续 / 设置 / 回主菜单（Esc 触发，与原有 hud 暂停遮罩叠加）
- **设置项**：主音量 / BGM 音量 / 音效音量 / 屏幕震动 / 精简 HUD
- **持久化**：`user://settings.cfg`（ConfigFile），启动时读取、修改即存
- **音量实现**：不新增 audio bus（避免手写 bus 布局出错），改成系数——`Game.sfx()` 与 BGM 播放器各自乘系数，主音量走 Master 总线
- **精简 HUD**：隐藏左上 meta 面板（因子/共鸣/三流派/主题四行）与状态条

## 四、BUG-001 真根因（本轮最重要的产出）

这个震荡从 Sprint 3 就存在，Sprint 4 我判为「已结案」，实为**只缓解了症状**。本轮定位到**两条独立真因**：

### 真因 1：`_telegraphs` 跨房间泄漏（累积性）
`_telegraphs` 在 telegraph 创建时 `+1`、完成时 `-1`；但进房清理会把上一批 telegraph 节点 `queue_free`，**它们的减计数回调随节点一起丢失** → 计数只增不减、跨房间累积 → 该房间永远达不到「`_telegraphs == 0` 且无敌」→ 永远清不了场 → 自动驾驶反复进出同一房间。
**修复**：`_enter_room` 里 `_telegraphs = 0`（与 `_room_spawned = 0` 同处重置）。

### 真因 2：每层起点房的 `cleared` 永远是 false
`_enter_room` 只给非 start 房设 `skip_loot`，**start 房从生成到清场 `cleared` 始终是 false** → BFS 的「未清房间」目标每次都命中起点房 → 玩家在起点房与别的房间之间反复折返。
**修复**：start 房进场即置 `info["cleared"] = true`。

### 附带保留的两处加固（Sprint 5 已做）
- BFS 分支不再按 `d.locked` 过滤：目标房还在战斗时门是锁的，但「贴门 1.2 秒强制过门」照样能进，按锁过滤会静默落到兜底。
- 终端兜底只走 `visited == false` 的方向，无解即停。

### 验证
修复前：种子 3/4/5 反复出现 43 / 64 / 123 次过门与 4 次 `[SMOKE-LOOP]` 命中。
修复后：**十次连跑（种子 2/3/4/5 各两次）全部 `loop=0`**，过门回到 6–17 的正常区间；最终六种子基线同样 `loop=0`。
