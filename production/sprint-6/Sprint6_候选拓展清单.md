# Sprint 6 候选拓展清单（路线图之外的补充）

> 日期：2026-11-05
> 依据：SPR5-FROZEN-1 实读现状 + 实跑截图 + `Sprint5_拓展路线图.md`（A/B/C 三档）之外的补充
> 结论先说：**当前瓶颈不在内容量，而在「手感趋同」「没有局外层」「HUD 没有分层」「没有主动操作型内容」**

## 零、扩展前必须先做的两件事

| 项 | 现状证据 | 为什么必须先做 |
|-|-|-|
| **设置 / 主菜单** | 全项目只有 1 个场景 `scene/game.tscn`，开局直接进游戏；有 3 首 BGM（`Assets.MUSIC`，按房间类型切）与音效池，但**无处调音量**，也没有 meta 进度入口 | 局外 meta 进度（路线图 B1）必须有落点；玩家现在连音量都改不了 |
| **HUD 精简 / 信息分层** | 左上已 3 块面板（血条 + 状态条 + meta 四行），右上小地图 + 计时层数，左下技能/武器槽，底部提示、连杀、toast | HUD 信息密度接近上限，再加任何显示类内容都会互相遮挡 |

## 一、体验层（路线图未覆盖）

### E1 · 设置与主菜单（独立有价值，也是 B1 的硬前置）
- 内容：主菜单（开始 / 每日挑战 / 图鉴 / 设置 / 继续）/ 设置页（主音量、BGM、音效、窗口模式、按键说明、HUD 精简开关、屏幕震动强度）/ 暂停菜单
- 成本：M（新增场景 + 一套 UI 控件约定）
- 风险：当前是单场景架构，引入多场景要先定清楚 meta 存档与局内状态的边界

### E2 · HUD 精简与信息分层
- 内容：提供「精简」开关；把 meta 四行（因子 / 共鸣 / 三流派 / 主题）合并成一行；血条旁只保留当前生效的套装徽章
- 成本：S–M
- 价值：让后续「再加一行显示」不再有压力

### E3 · 新手引导
- 内容：前 3 分钟渐进提示——炸弹可炸暗门、源石的用途、套装进度、诅咒房的代价
- 成本：S（复用现有 toast / banner）
- 价值：核心机制（炸墙找隐藏房）目前完全靠玩家自己发现

## 二、低成本内容层（感知强、成本极低）

### F1 · 敌人 AI 参数化 —— **性价比最高的单项**
- 现状：`slug.gd` 只有 8 个 AI 函数（chase / erratic / spitter / turret / bomber / leap / summon / boss），**弹速、射速、射程、弹幕数、转向全部硬编码在函数里**；28 种敌人因此手感趋同，玩家只认得出「追我的」和「射我的」
- 做法：把这些抽成 `Data.ENEMIES` 的可选字段（`ai_shot_speed` / `ai_shot_cd` / `ai_range` / `ai_turn` / `ai_burst`），函数内取默认值
- 成本：S–M（data.gd 若干字段 + slug.gd 约 8 处读取）
- 价值：一次改动就让 28 个敌人的手感拉开差异；以后加怪只改数据、不碰 AI 代码
- 依赖：无

### F2 · 主动遗物
- 现状：10 个遗物全是「改字段」的被动（吸血、反伤、弹墙、减速、暴击、无敌、浮游炮、加血上限……），**没有主动道具**
- 做法：加 4–6 个按键释放型遗物（环绕护盾 / 冲刺 / 浮游炮齐射 / 投掷毒云 / 冻结弹）
- 成本：M（键位与冷却 UI）
- 价值：build 从「数字变大」变成「操作变化」，这是肉鸽最核心的乐趣

### F3 · 敌人编队
- 现状：敌人按池子独立刷，房内没有战术结构
- 做法：刷怪池改按「小队模板」抽（护盾怪 + 召唤怪 / 治疗怪 + 冲锋怪 / 狙击 + 拆弹），让房间有战术意图
- 成本：M（data.gd 加模板表 + `_spawn_batch` 改抽法）
- 价值：房间不再是一堆同质怪

### F4 · 主题地形（把 A2 的楼层主题做成看得见的地形）
- 现状：A2 的楼层主题只有环境规则 + 地板色调
- 做法：加地形层——岩浆地块持续灼烧、冰面打滑、毒沼减速、藤蔓阻挡
- 成本：M（地形层 + 碰撞处理）
- 价值：主题从「数字生效」变成「看得见」，记忆点更强

### G1 · 里程碑提示（几乎零成本的正反馈）
- 现状：toast / banner 机制已存在，但只用于奖励播报
- 做法：复用它做里程碑播报（连杀 20 / 首次进入诅咒房 / 集齐套装 / 首杀精英 / 到达第 N 层）
- 成本：S
- 价值：让玩家意识到自己做到了什么

## 三、排序建议

| 顺位 | 项 | 一句话理由 |
|-|-|-|
| 1 | **F1 敌人 AI 参数化** | 成本最低、感知最强，且让「加怪」从此只改数据 |
| 2 | **E1 设置与主菜单** | meta 的硬前置，顺带解决「调不了音量」 |
| 3 | **G1 里程碑提示** | 几乎零成本，立刻有正反馈 |
| 4 | E2 HUD 精简 | 后面所有显示类扩展的地基 |
| 5 | F2 主动遗物 | build 质变的关键 |
| 6 | E3 新手引导 | 降低流失 |
| 7 | F3 敌人编队 | 房间战术结构 |
| 8 | F4 主题地形 | 楼层主题的视觉化延伸 |

## 四、我的判断

当前内容量其实**不薄**了：房间 10、敌人 28、升级 14+3 套装、遗物 10、词缀 6、因子 6、楼层主题 4。继续堆同类内容的边际收益很低。真正的四个瓶颈是：

1. **28 个敌人共用 8 个硬编码行为** → 手感趋同（F1 解决）
2. **没有局外层** → 玩 10 局和玩 1 局没区别（E1 + 路线图 B1 解决）
3. **HUD 没有分层** → 继续加显示类内容就会挤（E2 解决）
4. **没有主动操作型内容** → build 变化只体现在数字上（F2 解决）

如果只做一轮，建议 **F1 + E1 + G1**：一个让已有 28 个敌人立刻产生手感差异，一个补上局外层的落点并解决音量不可调，一个几乎零成本地补正反馈。
