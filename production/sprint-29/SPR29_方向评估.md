## 四 候选 A · 发现度改写深渊起点（推荐）

| 维度 | 内容 |
|---|---|
| 现状（互不引用） | 发现度经 `codex_boons()` 只读派生、开局注入 shield/diamonds/max_hp/suffix；深渊档开局注入 hp/speed/dmg 乘子。两套分别落在 `run_seed` 前与 modifier 后，都零 rng 消费，却从不互看——集齐图鉴的长期积累，在你决定打第几档时**一点都没被兑现** |
| 改写关系 | 让发现档数作为深渊开局条件的**只读输入**：探索得越全，你进入高层的起点越从容。不新增字段、不新增表，两系统各自的既有数据一字不改，只让其中一个的输出成为另一个的输入 |
| 为什么值得做 | 给图鉴一个「为什么要集齐」的跨局理由，把被动收藏变成主动的长期投资；正好命中「Dynamics 贫乏」——产生一个新决策情境（我现在冲档，还是先把图鉴补齐再来），而不是新机制 |
| 红线 / E1 | 触碰冻结红线：**无**；E1：**可守**：发现度在 `run_seed` 前、深渊档在 modifier 后，两者都零 rng 消费，任一侧接入都不动 rng 序列；指纹只含 rooms+kinds，**零重定** |
| 若不做会怎样 | 图鉴继续只是被动收藏、深渊档继续只是一组孤立乘子，「长期积累→当下选择」这条链仍断着；诊断「Dynamics 贫乏」本批不缓解，但无结构性回退 |

## 五 候选 B · 难度改写净化代价（备选）

| 维度 | 内容 |
|---|---|
| 现状（互不引用） | 深渊档（S21）缩放敌人；净化（S28）确定性地作废本局结算加成。两者同处结算链路，但「放弃的那一份加成有多重」与「你选了多难的一档」从未挂钩 |
| 改写关系 | 让当前难度档决定净化所放弃代价的**权重**：档越高，那次「忍不忍」越值得犹豫。复用既有 `abyss_tier` 与 `purified_run`，不新增实体/字段 |
| 为什么值得做 | 直接对冲 S28 在册的 R2「恒可支付偏置」——净化不再是一个永远该点的按钮，而随难度变成真权衡；半径比 A 小，但 Dynamics 增量也薄一档 |
| 红线 / E1 | 触碰冻结红线：**无**（结算加成是既有常量；不碰 SHRINE_OFFERS 机制字段；不借机修 R4 存档）；E1：**可守**，只读布尔与档位，零 rng |
| 若不做会怎样 | 净化在穷局里仍是那个「唯一亮着的按钮」，R2 偏置继续挂着；但它比 A 更贴结算经济，优先级让位于 A |

## 八 推荐 + 一句理由

**推荐候选 A（图鉴发现度 × 深渊难度档）。** 它让两条本就都在开局、只读、零 rng 的长线第一次互相兑现——零新字段、零新实体、零冻结触碰，却第一次给了「集齐图鉴」一个能说出口的跨局理由，是三者中最纯粹的关系型 Dynamics。

## 九 已知风险与缓解

| 风险 | 说明 | 缓解 |
|---|---|---|
| 平衡失控 | 发现度折扣过大 → 深渊档失去难度意义 | 只做「开局缓冲」量级、不动各档乘子本体；用现有深渊探针覆盖 t0/t10 两端；**新增验数值断言**验「发现度档位 → 起始缓冲值」映射真的生效，否则这条 Dynamics 只有声明没有守卫 |
| 支柱漂移 | 玩家感觉「不集齐图鉴就不能冲高层」→ 收藏变义务 | 措辞只陈述「更从容」、不写「必须」；保持低发现度仍可正常选档 |
| E1 指纹 | 改起始 hp/speed/dmg 后指纹是否漂移 | **零重定**：指纹只打房间坐标 + kind，不含玩家起始数值，rooms/kinds 逐字不变（S27/S28 三次核验同此判据） |

| 候选 C 误立项 | 被读成「高连绩解锁新复合格」 | 本稿已给「不建议本批」结论，连绩数据保持在既有回声通道内只读 |
