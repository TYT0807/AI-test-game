# Sprint 26 规划草案 · 六道卷深度绑定 + 视听大换血

> 主理人（创造层）草案，2026-11-15。走游戏开发工作室分工，方向已定、不再开口。

## 一、诊断与定位

Sprint 25 完成的是**命名层平移**：主标题、货币、敌人、主题、升级的显示名换成六道卷母题（见痕 / 残响 / 游魂 / 往生脉），但世界观仍停留在「名字」——玩家看到的机制、读到的文案、听到的声音，骨子里还是那套矿窟射击。

本批目标：从「换名字」进到「换灵魂」。**不新增机制**（S16 诊断：Mechanics 已过饱和，优先做系统间关系），把六道卷的世界观骨架转译进游戏**已有的**每一层表层——视觉、听觉、文案语义、意义框架。

「大换血」的准确含义（冻结规格约束下）：**三层表层全换，机制层守住**。视觉全换、听觉全换、文案语义全换——这是能做的最大改动量，且不碰红线。

## 四、红线（不可越）

- **F1**：`FLOOR_THEMES` 8→12 永不接；只改 `name` 显示值与手记 value。
- **FLAVOR**：74 条 key 前缀不动、条数不动，只改 value（validate 覆盖门按 `/` 前缀分桶计数）。
- 冻结规格全不动：`CODEX_KINDS` 六类 / 图鉴 id / `ACTION_DEFS` 18 / 播报格式串 / `Meta.STATS_KEYS` / `UNLOCKS` / `CODEX_BOONS` 四档。
- **E1** 零新增 `Game.rng`；**E6** 零 raw delta；零新增实体 / 资源 / 动作；`FLOOR_THEMES[*].tint` 下的贴图主体保持中性明度。
- 贴图替换：同名 / 同路径 / 同尺寸 / 同格式覆盖，不动 `.import`、不动 `assets.gd T_*` 常量与文件名（`源石虫.png` 批一零动纪律延续）。
- BGM 保留 `.mp3`（`assets.gd:148 m.loop=true` 依赖 `AudioStreamMP3.loop`）。
- 六道卷为**自有 IP**：不取原文正文 / 段落 / 文风 / 句式，只取世界观骨架 / 母题 / 人物设定；须过取材铁律与真实人名机构模糊化（红线 #15）。
