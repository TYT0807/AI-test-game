| 项 | 实测 |

| 合成方式 | 纯标准库 Python 生成 PCM（struct+math，无 numpy）→ ffmpeg `mp3_mf` 编码 |

| 响度 | -20.3 / -21.0 / -20.6 LUFS-I；True Peak -9.8 dBTP（无削波） |

**踩坑与修复（如实记录）**：`mp3_mf` 首次编码写出损坏的 Xing 头 → ffmpeg 探测时长错成 8.46s（实际解码 30.03s 数据完整）。根因是默认 `-write_xing 1` 写的帧数元数据与实际不符。加 `-write_xing 0 -id3v2_version 0` 后得到裸 `fffb` 帧、无 ID3、时长/码率全正确，与 S25 现存 BGM 同构。**这是本批唯一技术故障，已彻底修复并复验。**
