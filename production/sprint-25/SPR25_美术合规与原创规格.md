### 2.2 调色板口径（全 3 张统一）

- 索引色感、每图 ≤16 色；纯透明底、无半透明羽化、无抗锯齿（`IPix.ttf` 同款硬边气质）。

### 2.3 「换图不改代码」三条硬前提（缺一即破）

1. **文件名逐字不变**（含中文 `源石虫.png` / `浮游炮.png` / `动态瓦片.png` 等）；`assets.gd:5-12` 的 `T_*` preload 路径、`menu.gd:40`、`data.gd` 的 `atlas="slug"/"enemy2"` 全部不改。
2. **尺寸 / 色型逐字不变**（IHDR 见 §2.1），RGBA8 透明底；`.import` 仅映射路径与参数、不含源图 md5，**同尺寸覆盖无需改任何 `.import`**。
3. **行列坐标与 rect 常量逐字不变**：不得重排帧序、不得增删行列、不得改 `W_CELL/S_CELL/BOOM_FRAME/ICON_RECTS/DYN_*/TILE_*/TURRET_*`；不得增删 `GEN_NAMES`(56) / `MONSTER_NAMES`(21) / `KNOWN_ATLAS`(2)。

> **不成立的情形**：若同时把「源石 / 源石虫 / 浮游炮」文案改成原创术语，会碰 `FLOOR_THEMES`(8 项) 与 `FLAVOR`(74 条键前缀)、`玩法说明.md`、README → 属**数据表改动**，必然触发 `.gd` 修改、E1 确定性复核与冻结清单重定。此路径须另立项，不在「换图不改代码」口径内。

## 3. 原创视觉方向（承接「废弃矿窟 · 六道卷 · 人间道」）

1. **存在即被看见，代价是磨损**：角色 / 怪物不是「英雄与敌人」，是**在矿道里被灯光照到才显形的东西**；轮廓边缘允许缺失、断裂、被暗部吃掉一角，不做完整闭合描边。
2. **实用主义，不抒情**：延续 `production/sprint-23/SPR23_设计实稿.md:162` 定下的「废弃矿窟的实用主义」——短句、功能性、只陈述状态。视觉同理：工装、矿灯、编号牌、修补痕迹，**不加披风 / 徽章 / 翅膀 / 光环等身份符号**。
3. **汪曾祺式的克制 + 拒绝温情**：允许搪瓷缸、一截麻绳、一盏歪掉的灯这类**生活实物**，但只作为道具质感，不组织成叙事镜头、不做暖色柔光、不做角色特写；整体干燥、平直、不煽情。
4. **人间道的代价可视化**：`被看见 / 被记住 / 被爱` 三态用**极轻的视觉差**表达（灯照到的亮一档 / 编号牌多一道刻痕 / 影子少一块），绝不用大特效；「皆有代价」靠**越被记住越缺损**表达，而非增益特效。
5. **明确排除条款**：**不得与《明日方舟》任何角色的造型、配色、标志性元素相似**——禁用浅色长发 + 红黑主色、禁用角 / 尾 / 十字星瞳、禁用「W」字样与字母标识、禁用源石结晶 / 橙黑病蚀纹、禁用浮游炮的环形悬浮阵列、禁用制服与三角徽记。主角改为「矿灯记录员」，敌人改为「矿屑 / 塌方残留物」。

### 6.2 每批通用验收门

1. 尺寸 / 色型 / 透明底核对（Python 读 IHDR，方法同本稿审计口径）。
2. `git status` 只出现预期 PNG；**无任何 `.gd` / `.import` 变更**。
3. `validate.gd` 打印「自检通过」、无 `✗` 清单；无 `push_warning` 素材加载失败（尤其 `GEN_NAMES` 56 项）。
4. E1：同 seed 只比 `[SMOKE-META] fingerprint` 行，**不做整体日志 cmp**（README:37）。
5. 视觉：与 §3 造型锚点、§2.2 调色板一致；偏离项标注在交付文档里。

### 6.3 止损口径（「换图不改代码」被打破时）

- **触发条件**：出现任一 —— 需改 `assets.gd` 任何 rect 常量 / 需改文件名 / 需增删 `GEN_NAMES` / 需改 `FLOOR_THEMES`·`FLAVOR` / 出现 `.gd` diff / E1 fingerprint 漂移。
- **立即动作**：① 停止该批、不继续后续批次；② 用 `git checkout -- <该批 PNG>` 还原到 `4b96035` 基线（**只还原 PNG，不动任何脚本**）；③ 复跑 P0 基线验收；④ 把「为何必须改代码」写成独立议题回主理人，**由用户重新拍板是否立项**，不自行放宽约束。
- **回滚粒度**：按 PNG 单文件回滚即可，`.import` 与 `.godot/imported/` 由 Godot 自动重导入；因未改 `.gd`，冻结 `SPR21-FROZEN.md5` 34/34 不受影响、无需重定。
- **红线**：不得通过「改名 + 改 preload 路径」绕过约束；不得为迁就新图删除 `W.png` 第 4 列或 `源石虫.png` 第 5 行。
