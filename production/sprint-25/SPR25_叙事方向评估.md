## 一 一句话定位 + MDA / 自我决定论落点（三张力：载体 §一/§二 · 口吻 §五·5.1 撤销 · 合规 §〇/§五·5.2）

**定位**：不写一句新故事，只把世界观骨架、母题与人物设定**直接转成名字与语义**——图鉴、复盘、连绩本就是在记「这一局有没有留下痕迹」。**载体张力由此解**：12–18 字标签里，命名是唯一不加长度就能承载设定的位置（「设定层转译」），不需要长文本、对话、剧情节点，也不做文风对齐。

| 层 | 落点（不堆术语） |
|---|---|
| Mechanics | 零新增。玩法、表项、输入动作都不动；设定只换「叫什么」，不换「怎么算」 |
| Dynamics | 只加一层「回望」：局末把「发现度 / 连绩 / 最深」读成「这一局被记住了多少」，让 S23 跨局账本有了说法 |
| Aesthetics | 从纯 Challenge 往 Narrative 偏一格，不碰 Sensation / Fellowship；刻意不进局内、不给奖励 |
| 自我决定论 | **关联**为主（局与局间「被记住」的连续性）；**自主**极轻一格（命名留给玩家自己读，不解释、不教）；**胜任刻意不碰**——做成数值奖励即踩 P0 自激红线 |

## 四 推荐项：**候选 A · 设定层转译**（明确一个，如实复核后维持）

1. **用户口径反而收窄到 A 这一条路**：拍板①把「原文 / 段落 / 文风 / 句式」全部移出可用范围，B 原本的文风前提不再成立、C 也退回状态标签语义重指；剩下唯一不新增系统、不写长文本的通道就是「设定 → 名字与语义」的转译，正是 A 的射程。
2. **唯一必然发生的一层**：批一只换图不动名，批二必须换名（§五 6 类）并接入自有设定；A 是这层的最小闭合，不做则批二无处落地。
3. **零风险面**：E1 零、冻结规格零触、零新增实体 / 资源 / 输入动作；是 S16「加关系不加实体」在叙事层的同型延续，不制造下一批返工。
4. **不推荐 B 的硬理由**：74 条批量改动是 M 级、需实稿先行 + 全量回归 + 覆盖门重跑，与「固化优先 / Mechanics 过饱和」诊断错配；且用户明确不回原文文本层，B 的「深度」只是把同一套转译铺得更广，不产生新 Dynamics。
5. **不推荐单独做 C**：只覆盖局末，母题不落到局内命名；保留 C 的零字段只读形态为可选第二步，代价见 §七拍板 1。
6. **价值边界（如实标注，不硬撑）**：A 只交付「名字与语义」，**不交付可读的设定 / 人物故事**——无剧情节点、12–18 字标签的载体里，人物设定的叙事厚度本就落不下来。若用户要的是「设定被读到 / 被感到」，三个候选都不够，须另立 M 级以上载体项目，本稿不提议、不评估。
