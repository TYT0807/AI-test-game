# AI 试手游戏

一个用 **Godot 4.7.2 / GDScript** 做的俯视角肉鸽地牢射击原型，由 AI 协作开发，用来试手玩法系统设计与工程流程。

## 项目概况

- 引擎：Godot 4.7.2，单场景 `scene/game.tscn`，GDScript
- 已有系统：11 种房型（含抉择圣所）、9 枚地窖印记、7 种敌人编队、8 条反应词缀、4 件主动遗物、8 种楼层主题、3 位主题 Boss、灾祸层、每日挑战、地窖图鉴与局末复盘、图鉴发现度被动
- 详细玩法见 [玩法说明.md](玩法说明.md)
- 各批规划、交付与核验文档见 `production/sprint-10` ～ `production/sprint-17`
